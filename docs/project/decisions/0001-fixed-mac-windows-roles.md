# ADR 0001: Фиксированные роли Mac и Windows

- **Статус:** Принято
- **Дата:** 2026-08-09
- **Проверено относительно:** `main` @ `3dc60ed`

## Контекст

Продукт решает конкретную задачу: оставить ежедневные инструменты на Mac, но выполнять Docker workload на отдельном Windows PC в той же private network. Симметричные роли, несколько hosts и несколько clients значительно расширяют discovery, trust, conflict resolution и UI.

## Решение или испробованный подход

В MVP Mac всегда имеет роль `mac_client`, Windows — `windows_host`. Connection/trust limit равен одной паре. Второй Mac получает busy или требует явного удаления существующего trusted peer.

Альтернатива с выбираемыми симметричными ролями и множественными peers отклонена для первой версии.

## Фактический результат и доказательства

Роли и connection limit находятся в lifecycle model, UI copy, README и pairing registry. Это уменьшает число допустимых переходов и даёт однозначное направление Docker workload.

## Последствия

- UI может использовать понятные fixed role labels.
- Не требуется scheduler или выбор активного Docker host.
- Windows нельзя использовать как client, а несколько Mac — одновременно.

## Почему принят текущий статус

Решение соответствует основному пользовательскому сценарию и реализовано в `main`.

## Условия повторного рассмотрения

Пересматривать после стабильного MVP только при подтверждённом пользовательском спросе на несколько hosts/clients и отдельном протоколе admission/ownership.
